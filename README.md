# Messenger MVP

Минимальный realtime-мессенджер без PWA и внешней базы данных.

## Требования

Node.js 18+.

## Установка

```bash
cd messenger-mvp
npm install
```

## Запуск

```bash
npm start
```

Открой:

http://localhost:3000

## Настройка через консоль

```bash
npm run setup
```

После этого можно изменить название приложения и порт.

## Тест двух пользователей

Открой приложение в двух вкладках/браузерах:

1. В первой зарегистрируй `alex`.
2. Во второй зарегистрируй `ivan`.
3. В `alex` найди `ivan`.
4. Открой чат.
5. В другой вкладке найди `alex`.
6. Отправляй сообщения.

Сообщения доставляются через Socket.io.

## Важно

Это MVP для тестирования. Пользователи и сообщения хранятся только в RAM и исчезают после перезапуска Node.js.
